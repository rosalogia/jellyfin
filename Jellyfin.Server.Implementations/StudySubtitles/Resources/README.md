# CC-CEDICT

`cedict_ts.u8.gz` is CC-CEDICT, a community-maintained Chinese-English dictionary.

- Source: https://www.mdbg.net/chinese/dictionary?page=cedict
- License: Creative Commons Attribution-ShareAlike 4.0 International (https://creativecommons.org/licenses/by-sa/4.0/)

It is used by the study subtitles feature for word segmentation, pinyin and English definitions.
To update it, replace the file with a newer export from the source above.
